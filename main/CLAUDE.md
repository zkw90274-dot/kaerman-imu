# CLAUDE.md — main 模块

> [根目录](../CLAUDE.md) · 双滤波器 IMU 姿态解算

## 初始化流程

1. `icm42688_init(NULL)` — 传感器自检 + 默认配置 (SPI 在驱动内初始化)
2. `calibrate_gyro()` — 零漂标定 (500 样本, ~2.5s)
3. `kalman_init()` — 卡尔曼滤波器初始化
4. `icm42688_get_all_data()` → `mahony_init(ax, ay, az)` — 用加速度计初始化 Mahony 四元数
5. 主循环: 读取数据 → 零漂补偿 → 卡尔曼更新 → Mahony 更新 → VOFA 输出

## 双滤波器对比

| 特性 | 卡尔曼 (Pipeline 1) | Mahony (Pipeline 2) |
|------|---------------------|---------------------|
| 算法 | 一维卡尔曼分别滤 Roll/Pitch | PI 互补滤波融合 6 轴 |
| 四元数来源 | Roll/Pitch 滤波值 → euler_to_quat | 四元数微分方程直接积分 |
| 振动自适应 | R 增大 → 降加速度计信任 | Kp 降低 → 降加速度计权重 |
| 运动自适应 | Q 增大 → 提高响应 | 无 |
| Yaw 处理 | 陀螺仪积分 + 死区 + 四元数乘法 | 四元数自然包含 (PI 修正) |
| 初始化 | identity 四元数（加速度计直接解算角度） | **加速度计初始化四元数**（首帧即准确） |
| 积分策略 | — | 条件积分（仅误差 < 1.0 时累积，防饱和） |
| 收敛速度 | 即时 | < 0.5s（加速度计初始化后） |

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 200 Hz (5ms) | |
| 陀螺仪量程 | ±1000 dps | ICM42688_GYRO_FS_1000DPS |
| 加速度计量程 | ±2g | ICM42688_ACCEL_FS_2G |
| 零漂标定 | 500 样本 | 启动时自动执行 |
| 卡尔曼 Q_angle | 0.001 | 过程噪声（角度） |
| 卡尔曼 Q_bias | 0.003 | 过程噪声（偏差） |
| 卡尔曼 R_measure | 0.03 | 测量噪声 |
| Mahony Kp | 8.0 | 比例增益 |
| Mahony Ki | 0.002 | 积分增益 |
| 振动阈值 | 0.08g | 偏离 1g 的程度 |
| 运动阈值 | 20 dps | 角速度幅值 |
| Yaw 死区 | 0.5 dps | 低于此值不积分 |
